# Contributors

Global Health Evidence is developed at the School of Public Health, University
College Cork. This file records the project's research and technical leadership
and what each role contributes. To cite the software, use
[CITATION.cff](CITATION.cff).

## Research and technical leadership

### Dr. Zubair Kabir — Principal Investigator and Public Health Lead

Provides the project's public-health leadership, GBD expertise, research
direction, interpretation, data stewardship and institutional coordination.

- Public-health direction and research questions
- Global Burden of Disease expertise
- Interpretation of results
- Data stewardship
- Researcher engagement
- Institutional coordination

### Abdul Razak, PhD — Technical Lead, Lead Developer and Applied AI/Data Science Lead

Leads the end-to-end design and implementation of the software platform.

Current contributions:

- End-to-end technical architecture
- GBD data-ingestion and validation pipelines
- API and dashboard engineering
- Statistical forecasting: exploratory linear-trend projections with
  prediction intervals
- Secure researcher access: sign-in, sessions and the encrypted GitHub Pages
  copy
- Automated software testing and reproducibility
- Technical documentation
- Deployment engineering

Planned work, not yet implemented:

- Development and validation of machine-learning forecasting methods
- Bayesian decision-support methods

## Keeping this file current

Project-specific contributions should be updated as the platform evolves. When
a planned capability is implemented and validated, move it from planned work to
current contributions in the same change that adds it. Individual code changes
are recorded in the Git history.
